## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Aaish48/Emerging-Lab.git
cd Emerging-Lab
```

### 2️⃣ Install Dependencies

For Node.js projects:

```bash
npm install
```

For Python projects:

```bash
pip install -r requirements.txt
```

### 3️⃣ Run the Project

**Frontend:**

```bash
npm start
```

**Backend (Node.js):**

```bash
node server.js
```

**Backend (Python):**

```bash
activate venv

python app.py
```
